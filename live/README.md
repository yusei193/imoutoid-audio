# NET RADIO — サーバー無しのネットラジオ（配信者ツール＋ゲスト＋聴取ページ）

PeerJS（WebRTC）だけで動く、サーバー不要のネットラジオ一式です。
配信者・ゲスト・リスナーはブラウザだけでつながります（音声はP2P、サイトは静的ファイルのみ）。
生放送中は**ライブチャット＆リアクション**も使えます（配信者のブラウザが中継ハブ。サーバー不要）。

```
net-radio/
├─ broadcaster.html   配信者コンソール（マイク／BGM／ジングル／ボイスチェンジャー／キューシート／ゲスト）
├─ guest.html         ゲスト用スタジオ（2人対談・マイク／ボイスチェンジャー）
├─ index.html         リスナー用ラジオページ（生放送 ＋ 24時間AIラジオ）
├─ vendor/peerjs.min.js  CDNが使えない時の予備
└─ preview-*.png      画面プレビュー
```

## 使い方

1. **配信者**：`broadcaster.html` を開く →「配信開始」→ マイクを許可
2. **リスナー**：`index.html?id=放送局ID` を開く → 再生ボタン（ID省略時は `kaeru-radio-live`）
3. **ゲスト**：配信者コンソールの「ゲスト招待リンクをコピー」を相手に送る → 相手が開いて「スタジオに参加する」

`https://` で置くのがおすすめです（`file://` でも動きますが、クリップボードやマイク許可が制限される場合があります）。
GitHub Pages などにそのまま置けます。

## 主な機能

### 配信者コンソール（broadcaster.html）
- **マイク**：ON/OFF（ミュート）／音量／デバイス選択／エコーキャンセル／ノイズ抑制
- **BGMデッキ（A/B 2デッキ）**：複数MP3のプレイリスト、再生・一時停止・次へ・シーク、音量、トーク時のダッキング（押している間だけ下がる）
- **クロスフェード**：曲の終わり3.5秒前（0〜8秒で変更可）から次の曲を重ねて切替。キューシートの連続再生もBGMプレイリストも無音なし
- **ジングル／効果音**：内蔵シンセ4種（OPジングル・ピンポン・ブブー・拍手）。外部ファイル不要
- **ボイスチェンジャー**：素の声／AMラジオ／ロボット／エイリアン／ライブエコー／低音ピッチ／高音ピッチ＋試し聞き
- **マスター**：L/R VUメーター、リミッター（-6dB）、マスター音量、モニター
- **放送設定**：局ID、番組タイトル、DJ名、ひとことメモ（変更は接続中のリスナーへ即反映）、リスナー用URLコピー
- **ゲスト（2人対談）**：招待リンク、接続状態、ゲスト音量、ミュート、切断、ゲストの声を聴く
- **キューシート（番組進行表）**：トーク／MP3／imoutoidアーカイブ／ジングルを並べ、↑↓で並べ替え、▶で実行、⏭で次のキューへ、自動連続進行、JSON書き出し／読み込み、localStorageに自動保存
- **💬 ライブチャット（リスナー反応）**：リスナー・ゲストの発言とリアクション（👏❤️🔥🎵）をリアルタイム表示。DJ発言はハイライトして全員へ配信、配信者の返信欄と「クリア」ボタン付き

### ゲストスタジオ（guest.html）
- マイクON/OFF・音量・デバイス選択、自分の声を聴く（試し聞き）
- ボイスチェンジャー（配信者と同じプリセット）
- ホストの音声（ホストの声＋BGM＋SE）の再生・音量・ミュート
- 接続状態（待機中／通話中）、5秒ごとの自動再接続
- **💬 ライブチャット**：リスナーの反応を見ながらコメント送信（ゲストの発言もリスナー全員に届く）

### リスナーページ（index.html）
- ON AIR／OFF AIRランプ、番組タイトル・DJ・メモ、ゲスト出演中バッジ
- 再生／停止、音量、リアルタイム波形
- **接続の現在地を常時表示**：画面下の小さい行に `peer:open / conn:open / call:recv / ice:connected / trk:1 / turn:on` を出し続ける（生放送が詰まったときどこで止まっているか一目で分かる）
- **24時間AIラジオ（AUTO-DJ）**：生放送がOFF AIRのとき、imoutoid音源146曲を時刻シードで選曲して連続再生。生放送が始まると自動で生放送へ、終わるとAIラジオへ戻る
- **AI DJ**：日本語音声合成で曲紹介。音楽を止めず、音量を30%まで下げて重ねる（ダッキング）。音声合成が使えない環境では自動で曲だけ流れる
- **💬 LIVE CHAT**：波形とプレイヤーの下にチャットパネル。名前（localStorage保存・空なら「匿名リスナー」）、本文、ワンタップリアクション4種。生放送中だけ送信でき、OFF AIR中は「生放送が始まるとチャットに参加できます」と案内。途中参加でも直近20件の履歴を表示

## ライブチャットの仕組み

```
リスナー/ゲスト ──{type:'chat', name, text} / {type:'react', name, emoji}──▶ 配信者
配信者（最新50件をメモリ保持） ─{type:'chat-msg', id, role, name, text, time}
                              ─{type:'react-msg', id, role, name, emoji, time}──▶ 全員
新規接続 ───────────────────◀{type:'chat-history', items}（直近20件）
```

- 中継は配信者だけ。チャット用のサーバーやアカウントは不要（既存の DataConnection を使う）
- 受信した名前・本文は `textContent` だけで描画（XSS対策）、本文200文字・名前24文字まで
- 同じ接続からの連投は10秒20件まで、送信側も350msの連打防止でガード

## 音声ルーティング（2人対談）

```
マイク → ボイスチェンジャー ─┬─────────────────────┐
BGMデッキA/B ───────────────┤                     ├→ リミッターA → mixedStream（リスナー）
ジングル/SE ────────────────┘                     │
ゲストの声 ──────────────────────────────────────┘

マイク → ボイスチェンジャー ─┬─ BGM ─┬─ SE → リミッターB → returnStream（ゲストへ）
                              （ゲストの声は入れない＝ハウリング防止）

ゲストの声 → ゲスト音量 → ミックス ／ 別途モニター（配信者の耳）
```

- ゲスト自身の声はゲストに返りません（自分の声が遅れて二重に聞こえるのを防ぐため）
- 配信者にはゲストの声が聞こえます（「ゲストの声を聴く」でON/OFF・音量調整）
- スピーカーだとハウリングするので、2人対談は**ヘッドホン推奨**

## 注意点

- **ブラウザ**：Chrome / Edge / Safari の最新版を推奨。`http(s)` での利用が確実です
- **局IDは公開されます**：PeerJSの公開ブローカーに登録するため、IDを知っている人は誰でも聴取・ゲスト接続できます。内輪で使うときは推測されにくいIDに変えてください
- **ネットワーク（STUN / TURN）**：STUN（Google / Cloudflare / Nextcloud:443 / Metered）に加えて、**Metered の公開TURN（`global.relay.metered.ca`、80/443 の UDP・TCP・TLS）を標準で組み込んである**ので、モバイル回線のCGNATなどNATが厳しい環境でも音声が中継されます。クレデンシャルは3ページとも先頭の `TURN_CREDS` 1か所にあり、一時的に別のTURNを使うときは URL に `?turn=ホスト|ユーザー名|パスワード` を付けるだけで上書きできます（`turn:` を無効にしたいときは `TURN_CREDS` の username を空に）
  - 2026-11時点の実測：認証不要の公開TURN（Open Relay の共有クレデンシャル、PeerJSの無料TURN、bistri、hubl、anyfirewall）はすべて停止・DNS消失。稼働しているのはアカウント制のMeteredのみ。
  - 無料枠は 500MB/月（P2P直結のときは消費しない）。使い切るとTURN経由の接続だけが止まり、直結できる回線では引き続き再生できます。
- **ローカルMP3**：ブラウザの仕様で、再読み込み後はファイルを選び直す必要があります（進行表の並び・タイトル・メモは残ります）
- **AIラジオの音源**：`https://yusei193.github.io/imoutoid-audio/` のMP3を直接再生します（imoutoid-audio リポジトリ自体は変更していません）
- **AI DJ**：`speechSynthesis` の日本語音声を使います。音声が入っていない環境では曲紹介だけスキップされます

## 動作確認（Playwright / Chromium）

- PC 1280×880・スマホ縦 360×740（リスナーは390）で横スクロール0・JSコンソールエラー0
- マイク取得（`--use-fake-device-for-media-stream`）と配信開始、VUメーター、リミッター
- ボイスチェンジャー7プリセットの切替（スペクトルでピッチシフト・リングモジュレーションを確認）
- クロスフェード（デッキA→B、ゲインの重なりを確認）、キューシートの並べ替え・実行・自動進行・保存
- AIラジオ再生と曲送り、生放送↔AIラジオの自動切替
- ライブチャット：リスナー→配信者の到達、全員へのブロードキャスト、DJ返信のハイライト、リアクション集計、途中参加の履歴、ゲスト発言、OFF AIRの案内、XSS（`<img onerror>`）が文字列のまま表示されること
- ゲストのミックスマイナス（ゲスト音声はリスナー側にだけ乗り、ゲスト返しには入らない）
